# 介绍

  • 极致轻量的开源 RGB 灯控软件，开发者为爱发电制作
    • 该软件入门难度偏大，使用异步控制器不建议使用该软件，建议使用 SignalRGB
  • 推荐使用华硕 / 技嘉主板的，代替原灯控软件来使用该灯效软件
  • 精粤用户请注意硬件问题，软件其实并没有精粤遇到的那么多问题
    如果遇到问题请自行解决

注意：电脑用户名不能是中文， 把电脑修改成英文，推荐使用数字 + 字母 (推荐 ascii 码表里面的字符，以确保兼容性)
