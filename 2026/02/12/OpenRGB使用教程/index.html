# 配置主板 / 控制器灯珠数量

  • 如果是主板需要设置每个接口的灯珠数量
  • 该设置默认是 0，所以是只渲染 0 颗灯珠
  • 需要设置灯珠数量才能设置灯效

键盘鼠标显卡等设备，无法设置灯珠数量，只能从源码上修改

# 弹窗设置灯珠数量

以下两个设置灯珠数量的界面都可以用，设置的灯珠数量是互通的

  • 这个用于设置渲染输出的灯珠数量，默认为 0，建议全部设置在 30 左右
  • 如果软件灯珠数量 < 实际可控灯珠，会导致实际多出的部分不亮

    如果使用异步控制器，根据 SignalRGB 的配置，根据实际的灯珠数量来选择，自行确认

# 设备界面配置灯珠数量

这个跟弹窗是一样的，不够交互有点复杂，需要直接选择通道

# 灯光模式介绍

Direct 模式:

  • 直驱模式，用于实时发送 RGB 信号
  • 控制器 / 内存条 / 主板用 Effect 实时渲染都依赖该模式
  • 如果没有该模式无法实时渲染灯效

其他的模式:
可能依赖调色板颜色
比如 G102 这个 stacic 静态灯效，可以用调色板调色

比如 G102 这个 wave 彩虹灯效，无法使用调色板调色

但可以设置一些其他的参数

# Effcet 插件

Effcet 插件严重依赖于 Direct 灯光模式，如果没有个该模式，无法正常使用 Effect

# 如果没有 Direct 模式

如果你的主板 / 内存条 / 显卡不支持 direct 模式

  1. 没有该模式不支持实时 RGB 数据传输，没法用 Effect 实时渲染，会识别不到该设备
  2. 直接使用灯光模式切换固定的灯效吧

铭瑄精粤，海盗船内存如果不能使用 Effect 推荐使用模式来设置灯效

# 启用灯效

  1. 开启灯效开关
  2. 预览灯效小视窗
  3. 选择对应的的设备来在这个灯效里运行

# 右边切换灯效方向 / 亮度

  1. 打开亮度条开关，拖动亮度条，调整亮度
  2. 切换灯效流动方向

# 纯色灯效

  • 选择 -> 特殊 - 面具 这个灯效
  • Effect 里面并没有纯粹的纯色灯效，用这个灯效代替纯色，只设置颜色，不要修改其他参数
  • 左边第一个颜色就是这个灯效的颜色设置

# 彩虹灯效

  1. 选择 -> 彩虹波 - 自定义彩虹
  2. 选择对应的设备来在这个灯效里运行
  • 可以通过调整预设来切换彩虹效果

# 多灯效

  1. 一个灯效渲染一套设备
  2. 可以用多个灯效选择不同的设备

# 灯珠配置设置

  1. 选择通道进行设置
    如果设置之后不弹窗了，可以在设置里打开 “重新扫描时运行区域检查”
    打开之后重启软件就应该能重新设置灯珠数量了
  2. 精粤主板注意事项
    精粤主板只有在第一次弹窗才能进行进行灯珠设置
    后续都没办法在软件内重新设置，只能删除缓存才能重新设置
  3. 部分可以可以选择在设备界面选择通道进行设置
