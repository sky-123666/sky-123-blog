# 安装环境

  • 注意电脑用户名不能是中文， 把电脑修改成英文，推荐使用数字 + 字母 (推荐 ascii 码表里面的字符，以确保兼容性)
  1. 安装 PawnIO 驱动 (Github 下载链接，请注意网络环境)
  • 该运行库用于访问系统低级设备
  1. 安装 C++ 运行库 (精粤官网下载链接，白嫖他们服务器)
  • 该运行库用于支持 C++ 程序运行

# 安装软件

安装好以上程序之后再打开软件，以免缓存文件出错

  1. 安装 OpenRGB 本体
  • 解压好之后，把软件目录随便放在哪里，然后把 OpenRGB.exe 右击发送到桌面快捷方式
  • 第一次务必管理员启动该软件，不然识别不到部分设备
  • 先忽略掉这个设置灯珠数量的弹窗，先去安装灯效插件

# 安装 Effect 灯效插件

  1. 下载灯效文件
  2. 安装插件
  • 在设置里面的把 effects 插件 install Plugin 导入进去，或者拖进来
  • 然后选择解压出来的灯效.dll 文件


    感觉安装完插件之后，重启软件，再设置中文会更稳定一点
  • 在设置里面切换成中文
  • 然后退出软件，重新管理员运行，查看 OpenRGB简单使用教程
    这样就安装成功了，接下来设置软件吧
