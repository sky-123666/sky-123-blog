# 介绍

  • 文件下载:SignalRGB 整合包
  • 如果出现问题可以查看其他的里面的一些进阶教程，可以处理一部分问题

# 步骤 1. 安装软件

# 安装软件本体

文件解压教程: 点击查看 () 如果你不会解压缩，我建议放弃后面所有步骤， 跳转
解压之后，打开附加包文件夹

  1. 找到 install_SignalRGB.exe，双击安装
  2. 这个是启动加载界面，已经安装成功了，正在启动软件
  3. 跳过登录受限于网络环境，东大无法正常连接 SignalRGB 服务器，且不需要登录 (使用本地灯效)

# 删除更新，保留稳定版本

这个软件更新之后经常出现问题，建议使用附加包里面的稳定版本，而不是从官网下载

  1. 打开任务管理器，结束掉 Update

  2. 右击 SignalRGB 打开文件所在位置
    Update 是软件自动更新模块，APP-2.5.xx 这个是版本号，目前稳定版为 2.5.28 版本

  3. 删掉 Update，任务管理器里面结束一下 Update 和 SignalRGB Core 如果不结束进程，会删不掉文件
    确保版本是 app-2.5.28 ，如果是大于这个版本的文件夹，那个文件夹删掉就行了

# 步骤 2. 安装汉化

  • 2.5.x 版本在 SignalRGB 的设置里的 Language 语言切换成 Chinese 即可

# 步骤 3. 安装附加包

  • 下载出来的附加包里面 WhirlwindFX 里面有很多灯效和模型文件
  • 把附加包里面的 WhirlwindFX 粘贴文在 C:/Users/ 电脑用户名 / 文档 ，然后重启 SignalRGB，这样就有更多灯效和模型文件了 如果安装之后没有更多灯效

当灯效和汉化都安装好了，来查看 SignalRGB使用教程 吧

# 其他

这里是进阶教程一般不会用到它
但是可以解决某些偶然出现的问题
当你遇见问题时，请详细阅读以下教程

# 认识 WhirlwindFX 内部文件

  1. Effect 灯效
  • 路径: WhirlwindFX/Effect
  • 内容：灯效文件
  • 文件里面有灯效的源码
  1. Plugins 插件
  • 路径: WhirlwindFX/Plugins
  • 内容：插件文件
  • 文件里面有控制器 / 键盘 / 鼠标的协议源码
  1. Components 组件
  • 路径: WhirlwindFX/Components
  • 内容：模型文件
  • 网友制作的风扇 / 霓虹线 / 灯光设备 模型都在这里面

# 修改附加包位置

SignalRGB 的设置里的 windows 设置内
找到附加包位置，可以自己切换路径，文件夹名字必须是 WhirlwindFX

如果安装附加包之后不生效，在这里受到切换到自己心仪的文件路径

# 问题排查:

# 软件无法安装，报错，闪退

视频链接

  1. 建议关闭杀毒软件后安装
  2. 重启电脑后再重新安装
  3. 注意电脑用户名不能是中文， 把电脑修改成英文，推荐使用数字 + 字母 (推荐 ascii 码表里面的字符，以确保兼容性)
  4. 需要在 BIOS 里面打开 AVX 指令集

# 安装完之后还是没有更多灯效

  1. 请查看修改附加包地址
  2. 检查目标目录的 WhirlwindFX 默认文档里面的 Effect 文件夹内 是否有文件， 如果没有重新复制进去
