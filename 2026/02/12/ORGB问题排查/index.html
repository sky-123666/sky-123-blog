# 软件打不开

删掉缓存，重新设置
这里是 OpenRGB 全部的缓存文件
一般需要全部删掉

  • 路径: C:\Users\ 用户名 \AppData\Roaming\ OpenRGB
    • 路径: C:\ 用户 \ 用户名 \AppData\Roaming\ OpenRGB
    • 缓存文件全在这里面，设置的数据不多可以全部删掉
  • OpenRGB\plugins\settings\effect-profiles
    • 灯效配置 配置文件，可以尝试保留
  • OpenRGB\plugins\settings\virtual-controllers 可视化布局
    • VMap 配置 配置文件，可以尝试保留

# 硬件不识别

  • 右击管理员运行该软件
  • 还不识别就是不适配，或者缺少芯片组驱动
    • intel Chipset
    • AMD Chipset
    • 建议优先从主板官网下载，不行的话用华硕吹雪同芯片组型号的驱动
  • 查看 OpenRGB 官网适配列表: 查看

# 开机不自启

选择其中一种方式，推荐第二种

  1. 设置里面打开，开机自启动
  2. 任务计划程序:
    • 可以让 OpenRGB 以管理员运行自启动，设备识别更好
