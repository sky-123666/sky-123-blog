开机灯效注意事项:

  • 使用 Yico Sync 保存之后，那个灯效会一直运行
  • 等 SignalRGB 或者 OpenRGB 启动之后，会接管控制器，覆盖开机灯效效果

如果和 SignalRGB 用时打开，软件会冲突，可能会爆闪

# 配置模型

  • 步骤说明:
    • 调整设备映射的模型
    • 在顺序设置里面给对应的接口选择对应的模型
  • 注意：直接选择模型，不推荐用导入模型库除非没有你风扇的模型

从 A1 号接口开始配置，把每个接口都要配置一下

点击对应的接口，对应的接口接的设备会亮起蓝色，然后选择对应的模型
如果该接口没有亮起，说明没有连接设备，把灯珠设置成 0

查看视频: 5:11 秒 ——>7:22 秒

  • 操作说明:
    • 点击选择对应的接口，对应的接口会亮起蓝色，然后给设备添加模型
    • 注意：如果灯珠数量为 0，对应的接口就算有设备，也不会亮
    • 如果 设备实际灯珠数量 > 设置的数量 。设备不会全部亮
  • 细节补充: 其他

# 设置顺序

  • 步骤说明:
    • 联动的设备会共用一个灯效
    • 让设备按顺序流动灯光

在右边打开需要联动的设备

在左边设置顺序，按照想要顺序让设备亮

查看视频: 7:22 秒 ——>8:13 秒

# 调整方向

  • 步骤说明:
    • 勾选反向，修改设备灯光流动的方向
    • 让灯效流动的方向正确

勾选反向切换到正确的方向，让设备流动的方向改变

查看视频: 8:13 秒 ——>10:08 秒

# 设置灯效

  1. 霓虹线流星
  • 关闭联动
    设置里打开霓虹线 max 灯效，使用流星灯效，让霓虹线达到流光的效果
    查看视频: 10:08 秒 ——>11:19 秒
  1. 流光
    勾选联动的设备，会共用一个灯效，按照排序亮
    个人推荐:
  • 序列
    • 序列是两个颜色交错亮
    • 如果 2 个颜色一样，开机时候，只亮一次就常亮了
    • 如果 1 个正常色 1 个黑色就可以流光
  • 其他灯效也差不多，一般用序列灯效比较多

背景颜色一般都设置成黑色的，使用背景颜色，灯效可能会有点奇怪，不好搭配

# 保存

在左上角点击保存，保存成功之后灯效就存在控制器里了

关闭软件也可以亮设置好的灯效

# 其他

# 模型库

  • 为什么不安装模型库
    • 因为新版本已经包含加入了亿科贝拉的设备了
    • 其他的水冷 / 灯带，直接用通用灯带设置灯珠数量就行了，用 2D 模型灯效反而不好看
  • 为什么要添加模型:
    • 因为控制器 -> 风扇 / 霓虹线是单向传输信号，控制器不能获取到设备信息，通过手动添加模型来映射灯珠位置属于单工通讯协议

# 关于某些设备:

  1. 乔思伯 ZA 系列更新到最新版已经内置了模型，如果更新到最新版没有的话，导入 SignalRGB 的模型吧
  2. 幻面和幻界系列是通用模型的
  3. 棱镜 7EVO 用棱镜 7Pro 的模型适配可能更好
  4. 灯带如果想联动在一起一根一根亮，切换成通用灯带，而不是 120 灯珠霓虹线

# 关于轴心颜色

需要支持独立寻址才能设置，暂时只有亿科的异步设备能设置轴心颜色
所以一般用不到这个设置

# 为什么不能设置设备数量:

只有积木风扇可以设置设备数量

不建议深究内部的电路原理

# 双模开机灯效

  1. 双模开机灯效设定有点复杂建议不使用
  2. 这模式有一定的 BUG
  3. 设置前建议在设置界面把控制器恢复默认再去调整双模开机灯效
    逻辑:
  • 双模开机灯效 1 和 2 是两套独立的灯效
  • 开机时 双模开机灯效 1 把帧时间使用完之后，会切换到双模开机灯效 2

# 问题排查

  1. 识别不到控制器
  • 灯光有亮，检查 USB 接口
  • 灯光没亮，检查 SATA 接
  • 接线都正常：热插拔扁的 SATA 接口
  1. 灯效卡死
    • 热插拔扁的 SATA 接口
  2. ARGB 同步模式卡死
    • 检查接口
    • 热插拔扁的 SATA 接口
    • 找客服刷固件
    • 其实我也不会修
  3. 更新之后没有更多灯效
    • 老批次固件是这样的，买个新的
