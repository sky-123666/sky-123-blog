# 高级灯控软件

# SignalRGB

  • SignalRGB 是一款商业灯控软件，社区极其庞大
  • 灯效数量：海量 (Canvas, 只能单画布，单灯效)
  • 性能占用：比华硕奥创多一点
  • 进入 SignalRGB 教程导航

# OpenRGB

  • OpenRGB 是一款开源灯控软件，社区极其庞大
  • 灯效数量：少量 (OpenGL GLSL , 可以播放多个灯效，设置多个画布)
  • 性能占用：极低
  • 进入 OpenRGB 教程导航
