# 简介:

推荐两个软件一起使用，发挥最好的灯效

  • Yico Sync
    • 是控制器板载软件，用于设置开机灯效
    • 退出 SignalRGB 之后会一直运行 Yico Sync 设置的效果
    • 删掉 Yico Sync 也不影响控制器的板载灯效，真正 0% 占用
    • 因为程序保存在控制器里，并不能控制主板 / 内存 / 显卡 / 键盘 / 鼠标等设备
  • SignalRGB
    • 支持音乐律动，屏光同步 等效果
    • 当 SignalRGB 启动之后会接管控制器灯效
    • SignalRGB 功能强大，能控制主板 / 内存 / 显卡 / 键盘 / 鼠标等设备

# 控制器卡死的问题

  1. 建议使用我分享的 SignalRGB 整合包
  2. 把控制器模式恢复默认之后，再设置成开启板载灯效，以免卡死
